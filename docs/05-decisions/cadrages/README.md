# Cadrages

Documents de travail éphémères, en amont d'un ADR ou d'un plan : diagnostic,
lots, arbitrages ouverts. Un cadrage disparaît une fois son contenu passé dans
la documentation pérenne ; il n'est donc **cité par aucun autre document**, et
il n'est **jamais une source de vérité**.
