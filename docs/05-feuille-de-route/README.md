# Feuille de route

Les sujets importants qui restent à faire : pistes futures, dette, questions ouvertes. Ce qui y
entre et ce qui n'y entre pas : règle 10 de la [charte](../README.md). Une ligne quitte un
registre quand le sujet est fait ; ce qu'il produit vit dans la documentation.

| Document | Contenu |

| [pistes-optimizer-vitesse.md](pistes-optimizer-vitesse.md) | Les pistes pour accélérer la recherche des runes sans changer ce qu'elle cherche, et pour ses instruments de mesure et de vérification. |
| [pistes-degats-reels.md](pistes-degats-reels.md) | Les pistes de coups, d'attaques et de réglages de la modale « Dégâts réels » que le calcul ne compte pas encore. |
