# Interface — pistes futures

Ce que les fiches d'écran annonçaient comme prévu sans le décrire comme fait. Une piste est ce qui
n'est pas fait : avant de s'y fier, vérifier dans le code qu'elle ne l'a pas été depuis. Une piste
réalisée quitte ce registre ; ce qu'elle produit se décrit dans la fiche de l'écran. Dernière
vérification dans le code : 2026-10-13, aucune n'est faite.
